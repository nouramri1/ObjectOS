# ObjectOS

A Chrome extension exploring how everyday objects can become
personalized controls through webcam-based machine learning.

## Current progress

- Extension side panel

## Planned features

- Camera preview
- Learn custom object positions
- Control audio volume
- Presentation controls

## Run locally

1. Open chrome://extensions in Chrome.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select this project folder.
5. Open ObjectOS from the Extensions menu.
